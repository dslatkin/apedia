A "shard" is a fan-run server for Whispers in Akarra. Players have been running them since 2005, and two are online today.

## How shards began

In July 2005 Jens Bergensten released the game's server program and its editors, which let players host the game themselves and build new maps, monsters, items and quests. In February 2008 he published the source code as well, so shards could change the game itself.

## Shards today

Akarra X2 has run since 2018, Akarra Online joined it in 2026, and the game can now be played in the browser.

## Key dates

- **July 5, 2005:** The server program is released.
- **February 19, 2008:** The source code is published.
- **February 2018:** Akarra X2 goes online.
- **August 2026:** Akarra Online launches, and Akarra X2 moves into the browser in September.
