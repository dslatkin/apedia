A "shard" is a fan-run server for Whispers in Akarra. Players have been running them since 2005, and two are online today: see [Play Today](/community/play) to join one.

## How shards began

In July 2005 Jens Bergensten released the game's server program and its editors, which let players host the game themselves and build new maps, monsters, items and quests. In February 2008 he published the source code as well, so shards could change the game itself.

## Shards

Every shard, in the order they opened. The ones still running link to their websites, and [Play Today](/community/play) has more on getting started.
